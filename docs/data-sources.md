# Data sources and attribution

Firecloud's software, downloaded data, map assets, and reference material are
separate works. A repository software license does not relicense third-party data.

| Input | Use in this repository | Provenance |
| --- | --- | --- |
| NOAA GFS | Pressure levels, cloud cover, surface fields, and forecast timing | Herbie-backed GFS adapters in `predictor/gfs.py` |
| Open-Meteo | Weather and air-quality snapshots used by point computations | Source URLs and request fields in `predictor/fetch.py` |
| Natural Earth | Cartopy map boundaries and land/water context | Rendering modules and Cartopy's data cache |
| Satellite data | Experimental brightness-temperature and motion corrections | Adapters in `predictor/satellite.py` |
| NOAA HRRR | Historical experiments and paper | Legacy source in `predictor/fetch.py` |

Before redistributing data or operating a public service, check the provider's
current attribution, redistribution, and access terms. Include the generated JSON
sidecars when sharing forecasts so source and model-run provenance remain visible.

The historical paper carries its bibliography in
[`research/paper/references.bib`](../research/paper/references.bib).
Some source comments refer to a privately held practical forecasting manual.
That third-party document is not redistributed here, and its empirical thresholds
should not be presented as independently established physical constants.

The small historical paper figures are generated by the adjacent Python scripts.
Routine forecast output, downloaded grids, reference PDFs, and personal visual
comparisons are excluded from Git and build artifacts. The bounded
[Shanghai example](../examples/shanghai-sunset/README.md) is an intentional exception:
its original PNG, metadata, and manifest are preserved with verified checksums.
It uses NOAA GFS forecasts, Open-Meteo point-weather inputs, and Natural Earth context.
The sidecar pins the GFS run but does not retain the underlying Open-Meteo model/run.
Open-Meteo API data are provided under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see the provider's
[data license](https://github.com/open-meteo/open-meteo#data-license).
Credit [Open-Meteo.com](https://open-meteo.com/) when sharing this derived diagnostic.
See the
[NOAA/NWS data-use policy](https://www.weather.gov/disclaimer) and
[Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/).
NOAA/NWS information and Natural Earth maps are public-domain material under
those policies; Firecloud's derived diagnostic is an independent research product
and carries no NOAA/NWS endorsement.
