# Shanghai sunset: a published forecast case

This snapshot makes a real product inspectable without downloading weather grids
or installing the forecast package. It was captured from the project's published
feed on October 3, 2026. It is a forecast archive, not an observed sunset or a
measurement of forecast skill.

![Archived Shanghai sunset forecast](forecast.png)

Weather data by [Open-Meteo.com](https://open-meteo.com/)
([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)), alongside NOAA GFS;
transformed into Firecloud's derived diagnostic. Map context made with Natural Earth.

The center is below the diagnostic threshold. Some evaluated cells in the wider
domain have a higher index; that does not mean the center has a 21% chance of glow
or that the maximum describes Shanghai. The map uses display smoothing, so the
raw grid range need not appear as a sharply visible maximum in the image.

The product targets the predicted weather near sunset. Here the discrete GFS
step is **24 minutes and 11 seconds after the center event**, rather than an
observation taken when someone requests the forecast. `valid_time_utc` in this
historical sidecar records the requested event instant. The model's discrete
forecast time is derived separately from `source_label` and the model run.
The local pipeline also uses Open-Meteo point-weather snapshots. This sidecar
does not retain their underlying model/run provenance, so the pinned GFS run
does not completely specify every weather input needed to recompute this case.

## Verify the saved example

From the repository root, with Python 3.11 or newer:

```bash
python examples/shanghai-sunset/verify.py
```

The script uses only the standard library. It checks byte counts and SHA-256
digests against the original manifest, cross-checks product identity, and prints
the time relationship and center index. It runs offline and continues to work
after the live feed rotates or the forecast expires.

| File | Purpose |
| --- | --- |
| `forecast.png` | Original published map, renamed locally for readability |
| `metadata.json` | Original product sidecar, preserved byte for byte |
| `manifest.json` | Original manifest, including hashes and source revision |
| `capture.json` | Capture URL, timestamp, and local filename mapping |
| `verify.py` | Offline artifact and provenance checks |

The original sidecar's `image` field retains its published filename. The local
mapping is explicit in `capture.json`. Manifest paths resolve relative to the
capture URL, and may stop being served when the site replaces its snapshot.

## Request a current product

```bash
uv run firecloud --scope local --source remote --event sunset --lat 31.23 --lon 121.47
```

Use `--date YYYY-MM-DD` to select the desired local event day, especially from a
different timezone. The static feed must have a current matching product. Its
remote-only mode verifies delivery and freshness and does not start a GFS
download. To recompute locally, select `--source local`; real downloads can be
large and historical GFS availability is not guaranteed.

## How to read the evidence

The local pipeline uses GFS profiles, diagnosed cloud layers, and sunward geometry
to combine necessary-condition gates with quality modifiers. See the
[methodology](../../research/methodology.md) for the implemented assumptions.
The saved sidecar does not include detailed cloud layers or each gate's
contribution, so it cannot establish which particular cloud feature caused this
center score. Those claims would require a detailed diagnostic capture.

This example was generated by the linked historical revision. It demonstrates
product format, provenance, and delivery; it does not test later code changes
or validate accuracy. A validation case needs independent, time-matched
observations and a documented evaluation protocol.

The pipeline combines NOAA GFS profiles with Open-Meteo point-weather inputs;
the map context is made with Natural Earth.
Firecloud produces the derived diagnostic independently of those providers.
See [data sources and terms](../../docs/data-sources.md).
